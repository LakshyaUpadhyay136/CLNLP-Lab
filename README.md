## Overview
This repository contains laboratory experiments conducted for the Computational Linguistics and Natural Language Processing (CLNLP) laboratory course. Each experiment covers practical NLP tasks ranging from foundational data exploration and text preprocessing to advanced tokenization and semantic modeling.

## Repository Structure
Each completed experiment directory is organized as follows:
* **Documentation (`README.md`):** Complete overview, step-by-step procedures, method signatures, observation tables, and key analytical takeaways.
* **Notebook (`.ipynb`):** Fully executable Jupyter Notebook with localized relative data paths, annotated code blocks, and output figures/tables.
* **Datasets & Assets:** Accompanying raw text files (`.txt`), structured tabular data (`.csv`), models, or PDF specifications.
